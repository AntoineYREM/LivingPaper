# Architecture decision records

Short notes that say **why** a choice was made, so that nobody has to guess, and so that a change of mind is a conscious one.
To add one, copy the shape of an existing note (status, context, decision, consequences), give it the next number, and add it
to this list. A decision is never rewritten: a later note replaces it and says so.
