# Archived examples

These files were shipped with earlier versions of LivingPaper. They are kept for reference and are **not loaded** by the
application: it only reads the `*.json` files directly in `examples/`. To bring one back, analyze the book again with the
current version, export it and put the file in `examples/`.

| Files | Shipped with | Why they were replaced |
|---|---|---|
| *Le Malade imaginaire*, *L'Avare*, *Don Juan* | 0.1 | No story of the book, scene by scene (schemaVersion 1) |
| *Alice's Adventures in Wonderland*, *Around the World in Eighty Days*, *Cyrano de Bergerac*, *The Jungle Book*, *Madame Bovary* | 0.3 and 0.4 | No passages of the book. Three of these books are shipped again, analyzed from their English text, with passages |

The published [evaluations of the characters](../../evals/README.md) were made with the *Madame Bovary* and *Cyrano de
Bergerac* sheets of this folder.
