# Archived examples

These three examples (*Le Malade imaginaire*, *L'Avare*, *Don Juan*) were shipped with LivingPaper 0.1. They were analyzed
before the story of the book, scene by scene, existed (schemaVersion 1, no `storySummary`), so their characters do not know
the plot.

They are kept for reference and are **not loaded** by the application: it only reads the `*.json` files directly in
`examples/`. To bring one back, analyze the book again with the current version, export it and put the file in `examples/`.
